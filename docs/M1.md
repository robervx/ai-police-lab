# M1 — sesión local de referencia

La CLI ejecuta dos instancias de `ScriptedAgent` con el mismo contexto público y
guion `reference-script-v1`. Son agentes ficticios locales, no GPT ni Claude.
El agente recibe únicamente el aviso y los resultados de sus propias acciones.

El catálogo `controlled-citizen-v1` contiene preguntas exactas y respuestas
predefinidas para PL-001. Cada respuesta del catálogo exige que el hecho figure
en `knows`. No se realiza clasificación semántica ni inferencia con un LLM.
Las respuestas se registran como testimonios, separados de `public_evidence`.
El catálogo no cambia la verdad ni la versión del YAML.

Cada JSONL contiene una sesión, con `seq` consecutivo y metadatos iniciales:
identificadores, versión y SHA256 del escenario, semilla, contexto público,
proveedor local, versión del guion, versión del contexto y versión del ciudadano.
No hay parámetros de sampling ni consumo de tokens al no existir llamadas a modelos.
Los IDs y timestamps cambian entre ejecuciones; las acciones y sus resultados
son reproducibles. La etiqueta `prompt_version` identifica el contrato de contexto
del agente ficticio; no corresponde a un prompt enviado a una API.

La exportación usa creación exclusiva y una carpeta por ejecución. El replay
rechaza JSON inválido, secuencias discontinuas, IDs duplicados, mezcla de sesiones
y reinicios o eventos posteriores al cierre. Una traza sin cierre se muestra como
incompleta. No es una verificación criptográfica ni una reconstrucción del estado.

Los registros se exportan al finalizar cada sesión, no antes de cada transición.
Un fallo durante la sesión puede perder sus eventos en memoria. La persistencia
continua debe resolverse antes de usar estos registros como auditoría durable.
No hay base de datos, WebSocket, UI, API de proveedor o ciudadano LLM en M1.
